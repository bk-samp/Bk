# BK – assistente de voz (protótipo)
1. Abra a pasta no Android Studio (ele gera o Gradle wrapper) e rode no celular.
2. No app: permita microfone → ative "BK Assistente" em Acessibilidade → Iniciar BK.
3. Diga "oi BK": vai à tela inicial e responde "Oi, o que posso ajudar?".
Comandos: voltar, tela inicial, recentes, rolar para baixo/cima, abrir <app>, tchau.
